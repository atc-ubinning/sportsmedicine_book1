    III. 근생리학·운동생리학 (Muscle & Exercise Physiology)

    1. 골격근의 구조와 기능

    근육 종류: skeletal(수의근·가로무늬근) / cardiac(불수의근·가로무늬근) / smooth(불수의근·민무늬근, 장기·혈관벽) 구조 계층: myofibril(sarcolemma)<muscle fiber(endomysium)<fascicle(perimysium)<muscle(epimysium) 근섬유 구조: myofibril, plasmalemma, sarcoplasm(글리코겐·마이오글로빈 풍부), transverse tubules(신호전달 입구), sarcoplasmic reticulum(칼슘저장고) Sarcomere: actin(thin)+myosin(thick). A band(myosin영역)/H zone(순수myosin)/Z line(actinin고정)/I band(순수actin)/M line(myosin anchor). Sliding filament theory: 고정된 thick filament가 thin filament를 끌어당김. 수축시 A band 불변, I band·H zone 짧아짐 Alpha-motor neuron & Motor unit: 크기클수록 담당 섬유수 많음. Motor unit=α뉴런+담당근섬유. 섬유수 많을수록 힘↑. Muscle fibers of different motor units intermingled→편측수축 예방·균일장력 Sensorimotor integration: 감각신경→CNS→α운동뉴런→운동. 척수 또는 뇌수준 처리(spinal=lower motor neuron / brain=high motor neuron)

    근섬유 유형(하나의 근육에 혼재, 근원섬유 아닌 근섬유 종류)

    구분 Type 1(적근,slow) Type 2a Type 2x(백근,fast)
    근형질세망 낮음, 칼슘방출↓ 중간 발달, 칼슘방출↑
    운동뉴런 크기 작음(힘↓) - 큼(힘↑)
    대사 유산소↑무산소↓ 유산소+무산소 균형 무산소↑↑
    피로저항 높음 중간 낮음
    특성 지속력, 저강도 운동 짧은 고강도지구력 고강도
    Endurance순위 1위 2위 3위
    Power순위 3위 2위 1위
    • 근섬유비율은 근육·인종·성별 차이, 가자미근=보통 type1 동일. 양측 근육은 유사. 2~3세/사춘기=분화시기(1까지 변화가능), 성인=10%정도 변화(type2 내에서만)

    근수축 종류

    • Isotonic: concentric(관절각↓, sarcomere짧아짐, filament 중심으로 slide) / eccentric(관절각↑, actin 밀려남, 교차결합 유지한 채 근절 늘어남)
    • Isometric: 길이변화 없이 힘생성(교차결합 유지, 근절길이 불변)
    • Isokinetic: 등속성, 기계필요, 전ROM 일정근력(관절각따라 외력 자동조절)

    2. Bioenergetics & Exercise Metabolism

    연료: CHO(4.1kcal/g, mono/di/polysaccharide, glycogenesis/lysis, 골격근2500kcal저장, 장점=대사용이·무산소가능/단점=쉽게고갈=hitting the wall) / Fat(9.4kcal/g, triglyceride=1glycerol+3FFA, lipogenesis/lysis, 약70,000kcal저장=거의무한, 장점=많은에너지/단점=산소필요·분해과정필요) / Protein(4.1kcal/g, 9필수아미노산, 특수상황에서만 연료) Calorie: 1cal=4.2J, 1kcal=1000cal(물1g을1도올리는 열에너지)

    ATP: 유일한 활용에너지형태, adenosine+3인산. 대사효율(연료의 40~50%만 ATP화, 나머지 열방출, ATP→기계일 효율 약25%, 강도↑시 효율↓)

    ATP 생성 3경로

    경로 기전 ATP 생성량 지속시간 장점 단점
    ATP-PCr PCr → Cr + Pi + 에너지 (creatine kinase 촉매) - ~10초 빠르고 단순 PCr 저장량 적음, 재합성은 휴식 시에만
    해당과정(glycolytic) glucose 또는 근육 glycogen 분해 glucose→2개 / glycogen→3개 15초~2분(길어야 5분) 무산소 가능, 단시간 고강도에 적합 과정 복잡·오래 걸림, 젖산·수소이온 축적
    유산소(aerobic) 해당과정 후 산소 있으면 지방대사(β-oxidation)까지 진입 최다(16C FFA→106개) 장시간 ATP 생성량 최다, 지방=거의 무한동력 시작까지 지연, 고강도엔 부적합
    • 3시스템은 항상 동시작동, 강도·시간에 따라 기여비율만 변화(교대 아님). 무산소운동≠무산소성대사(등식 아님)
    • Lactate: 젖산 자체는 피로원인 아님, lactic acid가 lactate+수소이온으로 분해 → 수소이온이 근수축 방해→피로. 생산>제거속도일 때 축적, 휴식만으로 15~25분내 소실

    대사 측정

    • 직접측정: 연료 40~50%만 ATP화 / 간접측정: O2섭취·CO2배출량 기반 추정(정상상태에서만 정확, 유산소대사 활발할 때 유효)
    • VO2(1분당 산소섭취량)=CO×동정맥차 / absolute(L/min, non-WB운동) vs relative(mL/kg/min, 개인간 비교)
    • VO2max: 최대산소섭취량, 높을수록 좋음(동일강도에서는 낮은 산소섭취=효율적). 8~12주 트레이닝후 고원. 높다고 항상 좋은 퍼포먼스는 아니나 가능성↑
    • RER(VCO2/VO2): 0.7=지방100%, 1=탄수화물100%, 휴식시 0.7~0.8
    • MET: 1MET=3.5mlO2/kg/min=0.0175kcal/min=휴식시 소비량
    • EPOC(운동후초과산소섭취): fast component(ATP·PCr보충,혈액산소보충,CO2배출) + slow component(젖산제거,젖산→glucose/glycogen전환). 강도↑=EPOC↑=회복중 지방연소 용이
    • Lactate threshold: 생산>제거 시점, 무산소기여 급증, VO2max의 약50~55%. 높은 젖산역치=높은VO2max=좋은지구력
    • Crossover concept: 무산소↔유산소 지배전환 시점(VO2max 45~65%), type2섬유 동원↑, epinephrine↑→glycogen분해↑. 중강도에서 지방연소 절대량 최대(고강도엔 급감)
    • 지구력선수 성공요소: high VO2max, high lactate threshold, high economy of effort, 근섬유 최적분포

    피로(Fatigue): central(CNS관련, 운동단위기능저하·과훈련) vs peripheral(골격근자체)

    • 4대원인: ①에너지공급부족(글리코겐급감=hitting the wall, 운동후90~120분) ②대사부산물축적 ③근수축실패 ④근수축관장신경변화
    • 연료선택요인: 강도↑=glycogen비율↑ / 지속시간↑=지방산·혈당비율↑(유산소↑)
    • 근글리코겐 많을수록 피로지연, 적정운동+식이로 20%증가가능, 운동후 CHO섭취(단당류)가 효과적
    • 근경련(cramp): 신경근문제(전해질<신경근), passive stretching 효과적
    • DOMS: 격렬운동24~48시간후, 근섬유·결합조직 미세손상(젖산 아님), eccentric>concentric 유발, RICE·NSAIDs로 완화

    3. 심폐계 반응 (Cardiorespiratory Response)

    심혈관계 구성: heart(펌프)+blood vessels(관)+blood(매개체). 기능: 산소영양운반, CO2노폐물제거, 호르몬운반, 체온체수분조절, 면역 심장: 4chamber(심방2=receiving/심실2=pumping), 4valve(역류방지), 4vessel. 순환: 폐→폐정맥→좌심방→좌심실→대동맥→전신→대정맥→우심방→우심실→폐동맥→폐 Myocardium: LV가 가장 일 많이함(전신순환), LV심근 운동/질병으로 비대가능(양상 다름) — 유산소트레이닝=심실크기비대(eccentric hypertrophy) / 저항트레이닝=심실벽두꺼워짐(concentric hypertrophy) 심박조절: intrinsic(SA node 자발적 탈분극) / extrinsic(자율신경, 교감=NE분비·심박↑ / 부교감=ACh분비·심박↓, 둘은 지속적 비율싸움) Cardiac cycle: systole(수축기, SBP)/diastole(이완기, DBP). 3단계: 심방수축+심실이완 → 심방이완+심실수축(혈액방출) → 심방+심실 모두이완 Stroke volume: 서있을때<누워있을때(중력영향↓). 수축기에 약2/3방출. Frank-Starling law: SV=contractility+preload(EDV)+afterload(혈압·판막저항, 낮출수록 유리). EF(=SV/EDV)=수축능력지표 Cardiac output: Q=HR×SV, 안정시4.2~5.6L/min. 강도↑따라증가, VO2max부근고원 혈류분배: 안정시 골격근20%·장기50% / 운동시 골격근확장→80%↑(장기혈류↓)

    호흡: pulmonary ventilation(외부↔폐포)/diffusion(폐포↔모세혈관, 외호흡)/capillary diffusion(모세혈관↔세포, 내호흡). 흡기시 external intercostal수축→흉곽확장→폐압↓→공기유입 폐용적: tidal volume(1회환기량), residual volume(잔기량), vital capacity(전체-잔기량) 기체법칙: Dalton's law(분압), Henry's law(분압↑=용해↑), Fick's law(확산속도∝표면적, ∝1/거리) O2 in blood: 2%혈장용해+98%헤모글로빈결합(oxyhemoglobin). Hb감소=산소운반↓. 4globin+heme, 최대4O2/Hb. 산소분압↑곳(폐)=탈락적음, 낮은곳(조직)=탈락활발 avO2 difference: 안정시4ml/100ml→운동시15ml/100ml Myoglobin: Hb의1/4형태, O2친화도↑(쉽게안놓음), O2 deficit시 방출(임시유산소대사용 산소공급) CO2 제거: 단순확산, 조직분압>혈액분압시 이동

    목표심박수: absolute method(최대심박수[220-나이]×운동강도) / reserve method(여유심박수×운동강도+안정시심박수). 운동시 심박수 안정적일수록 좋음(Q고정가정시 심박수↓=SV↑) Ventilation: minute ventilation=tidal volume×breathing rate, 대사요구비례 증가(1회환기량 먼저↑후 호흡수↑)

    • Ventilatory threshold: 환기량>산소섭취량 시점, 젖산역치 반영, VO2max55~75%
    • Anaerobic threshold: 무산소대사비율 급증, 항상성유지 어려워지는 시점(젖산역치·환기역치와 유사)

    Detraining effect: 조금만 안해도 SV·Q·VO2max 급감(근산화능력저하)

    4. 트레이닝 일반원리

    개별성(individuality)·특이성(specificity)·가역성(reversibility, 중단시 적응소실)·점진과부하(progressive overload)·변이(variation)

    근력증가 기전 (순서대로): ①학습효과 → ②신경조절개선(운동단위동원↑, 신경동시성↑, 자가억제↓) → ③근비대 Hypertrophy(근섬유크기↑, type2에서활발, 저항훈련→단백질합성↑) vs Hyperplasia(근섬유수↑, 성인거의없음, 2~3세/청소년기만) Atrophy: 근육위축(섬유수감소는 노화·신경손상·병적상태만). Detraining(type2x영향최대) / Immobilization(일상사용이 많은 type1감소가 더 큼)
