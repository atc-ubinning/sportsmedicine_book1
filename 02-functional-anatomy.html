    II. 기능해부학 (Functional Anatomy)

    1. 운동학 기본 개념

    운동의 종류

    • Linear motion(직선운동): rectilinear(완전직선) / curvilinear(곡선형 선형)
    • Angular motion(각운동): 축 중심 회전, 인체 관절 움직임은 모두 각운동
    • General motion: linear+angular 결합(대부분의 신체 운동)

    면·축 기준 움직임 (항상 해부학적 자세 기준)

    면 움직임
    Sagittal(시상면) flexion/extension, dorsi/plantarflexion, hyperextension
    Frontal(관상면) abduction/adduction, lateral flexion, elevation/depression, radial/ulnar deviation, inversion/eversion
    Transverse(수평면) internal/external rotation, forearm supination/pronation, horizontal ab/adduction
    • 주의: foot pronation/supination은 순수 수평면 아닌 복합면(triplanar) 동작

    Arthrokinematics vs Osteokinematics

    • Osteokinematics(뼈운동형상학): 뼈의 육안적 움직임, 축·면에 따라 발생, 자유도(움직임 가능한 면의 수)로 표현, ROM으로 측정
    • Arthrokinematics(관절운동형상학): 관절면의 부수적(accessory) 움직임 — 정상적으로 동반되어야 정상 뼈 움직임 확보(결여 시 ROM 제한)
    • Rolling: 뼈 이동방향과 항상 같은 방향, pure rolling은 압박(compression) 유발 → 단독 발생 시 관절면 충돌·아탈구 가능
    • Gliding: rolling과 동반, 관절면 형태에 따라 방향 결정 — convex-on-concave: roll·glide 반대방향 / concave-on-convex: roll·glide 같은방향 (convex-concave rule)
    • Spinning: 한 자리 축 중심 회전, 단독 발생 안 함
    • 부가요소: compression(압박, 안정성↑) / traction=distraction(신연, 통증완화)
    • Glide 제한 시 roll도 제한 → ROM 개선 시 glide 함께 확인 필요
    • Valgus/Varus: 움직임이 아닌 결과적 정렬(형태) 용어, 항상 상위 분절 대비 상대적 위치로 판단
    • Forefoot valgus/varus: rearfoot 기준 전족부 정렬
    • Rearfoot valgus/varus: tibia 기준 후족부(calcaneus) 정렬

    근육 구조(Muscle Architecture)

    • Origin/insertion: 대부분 건(tendon)/건막 통해 부착 (brachialis는 근육이 직접 뼈에 부착하는 예외)
    • 형태 분류: strap(sartorius), segmented(rectus abdominis), spiral(supinator), fusiform(biceps brachii), fan/serrated(serratus anterior, pec major), pennate(finger flexors, gastrocnemius, deltoid — uni/bi/multi)

    PCSA (생리학적 단면적)

    PCSA = (근육 부피 × cosθ) / (근섬유 길이)
    • θ=근섬유 방향과 건 방향 사이 각(힘 전달은 건 방향) — cosθ 영향은 작고 fiber length가 더 큰 영향
    • 사선형(pennate)일수록 섬유 짧고 PCSA 큼(같은 부피에 섬유 더 많음)
    구분 평행형(strap) 사선형(pennate)
    힘 발휘(PCSA) 작음 큼
    수축 시 변위(excursion)·속도 큼/빠름 작음/느림
    ROM 유리 불리
    예 sartorius, biceps brachii gastrocnemius, deltoid
    • Excursion = ΔL(섬유길이)×cosθ → 사선형은 변위 면에서 항상 불리
    • Dynamic pennation angle: 수축 시 각도↑(부피 일정, 길이단축·옆으로 늘어남) → 단면적 내 섬유수↑ → PCSA↑
    • Force transmission loss: 각도↑ → cosθ↓ → 힘손실, 단 PCSA 증가가 보상해 오히려 힘 증가하기도 함

    근수축 종류

    • Isotonic: concentric(구심성, 짧아짐)/eccentric(원심성, 늘어남) — 관절각 변화로 모멘트암 변화 → 전 ROM 동일 토크 불가(엄밀히 모든 프리웨이트=등장성 아님, 특히 반동 동작)
    • Isometric(등척성): 길이 변화 없이 힘 생성
    • Isokinetic(등속성): 기계 필요, 전 ROM 일정 장력, 주로 OKC — poor carryover to functional testing(실제 스포츠 전이 낮음)

    Length-Tension Relationship

    • 능동 장력(CC, Contractile Component): actin-myosin 교차결합 정도 결정 — 근절 너무 짧으면(액틴 겹침) 또는 너무 길면(결합수↓) 힘↓, 적정길이(resting length, d0)에서 최대
    • 수동 장력(PEC+SEC)
    • PEC(병렬 탄성요소): 근막류(epimysium·perimysium·endomysium·sarcolemma), 신경자극 없이 작동, 신장 시 발생
    • SEC(직렬 탄성요소): 건+교차결합, CC와 직렬 — CC 힘 생성 시 SEC 먼저 늘어나 탄성에너지 저장·방출 (SSC/플라이오메트릭의 기계적 기반)
    • d0~120% 구간: 수동장력 더해져 총 발휘력 최대(플라이오메트릭에서 중요) / 120% 이상: 능동장력 급감·구조파괴 위험
    • Pre-stretch: 근건복합체 신장 후 재수축 → 더 빠르고 크게 수축(플라이오메트릭 원리)

    Load(Force)-Velocity Relationship

    • 속도↑ → 구심성 힘↓(느린 템포=큰 장력) / 속도↑ → 원심성 힘↑ 후 고원(plateau, 신장 속도 빨라도 힘 유지)
    • 최대 힘 = "빠른 속도의 원심성 운동"
    • 힘 결정요소: ①자극시점 길이(length-tension) ②수축속도(load-velocity)

    Motor Unit: 운동신경-근섬유 복합체. 정밀조절 근육(안구근)=신경1:섬유1 / 큰 힘 근육=신경1:섬유다수 근육 구조 계층: myofibril(sarcolemma) < muscle fiber(endomysium) < fascicle(perimysium) < muscle(epimysium)

    2. 신경계 기초 & Brachial Plexus

    • Spinal cord: 경추뼈 7개, 신경 8쌍
    • 신경계 구분: Somatic(수의적, 골격근) / Autonomic(불수의적, 내장·심장근) — 교감/부교감
    • Neuron 종류: Motor(efferent, CNS→effector) / Sensory(afferent, 말초→CNS) / Interneuron(연결)
    • 신경섬유: A fiber(α=운동·고유수용, β=촉각·압각, γ=근방추조절, δ) / B fiber / C fiber
    • 근육=muscle fiber(extrafusal)+muscle spindle(intrafusal) / 로마숫자(I,II) 분류는 감각기능 별도분류
    • Ascending pathway: 1st order neuron — 말초→척수(dorsal horn 진입)→척수반사 또는 뇌로 계속 전달

    Brachial Plexus: Root(5, C5~T1) → Trunk(3, superior·middle·inferior) → Division(2, anterior=전면근육·posterior=후면근육) → Cord(3, lateral·medial·posterior) → Branch(axillary·radial·musculocutaneous·median·ulnar). 쇄골 하 충격 시 상완 전체 마비·통증 가능. 상완 전체 저림=상완신경총 자체 압박 의심 vs 특정 근육군만=국소 신경 문제

    3. 어깨 복합체 (Shoulder Complex)

    개요: 안정성 확보되어야 가동성 확보 (dynamic stability에 근육 역할 중요)

    • Extrinsic muscle(origin이 견갑대 밖): 견갑골 고정
    • Intrinsic muscle(origin이 견갑대 안·insertion 상완골, rotator cuff 대표): 모멘트암 짧아 고정(안정화) 위주
    • 3 bones(clavicle·scapula·humerus) / 5 joints(SC·AC·GH·ST·coracoacromial[공간, 관절아님])

    ST joint(Scapulothoracic): 실제 관절 아님(인대 없음), 흉곽-scapular border 연결. 견갑골 움직임은 쇄골 움직임(SC·AC)+흉곽 형태(척추만곡)와 밀접

    • Coracoacromial arch: coracoacromial ligament, 상완골 상방전위 방지. 공간 좁아지면 greater tubercle이 내부조직 손상→부종→더 좁아짐 → 충돌증후군
    • Scapular tipping: 흉곽 만곡 못따라가며 견갑골 튀어오름(pec minor·serratus ant·rhomboid·trap·levator scap 불균형) → scapular dyskinesis 연관

    GH joint: ball&socket, 가동성↑안정성↓. Glenoid labrum이 안정성 보완(biceps LH·triceps tendon 연장선). 인대: superior·middle·inferior GHL(IGHL 전후 2갈래)

    GH(shoulder joint) ST(shoulder girdle)
    Flexion Upward rotation, protraction
    Extension Downward rotation, retraction
    Abduction Upward rotation, protraction
    Adduction Downward rotation, retraction
    Medial rotation Protraction
    Lateral rotation Retraction
    Horizontal abduction Retraction, downward rotation
    Horizontal adduction Protraction, upward rotation

    AC joint: 쇄골손상→scapula 영향. 인대: AC lig, coracoclavicular lig(conoid=medial, trapezoid=lateral, 하나 손상돼도 나머지 지지). MOI: FOOSH, humerus 하방충격

    SC joint: 유일하게 axial skeleton과 연결, articular disk 존재. 인대: anterior/posterior SC lig, interclavicular lig, costoclavicular lig. 움직임: elevation-depression/protraction-retraction/rotation(ST와 연동). Core muscle(복횡근) 활성 필요 — 사지 움직임 전 몸통부터 단단하게

    쇄골 부착 구조물: superior·anterior=deltoid / superior=trapezius / inferior=subclavius, conoid lig, trapezoid lig / anterior border=pec major / posterior border=SCM·sternohyoid·trapezius

    Bursae: subacromial bursa/space, subdeltoid bursa & sheath

    견갑골 부착 근육 (심층=안정성, 표층=가동성 경향)

    • Superficial: Trapezius(상부=후두골→쇄골외측1/3, elevation·upward rotation / 중부=C7-T3→acromion~spine, retraction / 하부=T4-T12→spine root medial, depression·upward rotation), Latissimus dorsi(T6-L5 극돌기~sacrum~posterior iliac crest→humerus biceptal groove, internal rotation·extension·adduction)
    • Intermediate: Rhomboid major/minor(T2-T5/C7-T1→medial border, adduction·downward rotation), Levator scapulae(C1-C4→superior angle, elevation), Serratus anterior(rib→medial border, protraction·upward rotation — 흉곽 밀착 핵심, medial border 불안정을 잡아줌)
    • Deep(Rotator Cuff, SITS): Supraspinatus(초기외전 0~15°+110°이상 담당, deltoid 관여 적은 구간에서 순수 검사 가능), Infraspinatus(외회전), Subscapularis(내회전), Teres minor(외회전) — 공통: 회전반경 작고 관절중심 가까이 부착, 주역할은 humeral head를 glenoid에 붙잡기(안정성>가동성), deltoid 전단력에 대항해 압박력 제공
    • 기타: Pectoralis major(clavicular/sternocostal/abdominal head, internal rotation·flexion·adduction·horizontal adduction), Pectoralis minor(3·4·5rib→coracoid, downward rotation·protraction·anterior tilt, 긴장 시 abduction 제한), Subclavius(1st rib→쇄골 아래, 안정화), Deltoid(anterior=flexion·horizontal adduction / lateral=abduction / posterior=extension·horizontal abduction·external rotation), Coracobrachialis(flexion·horizontal adduction), Teres major(adduction·extension·internal rotation), Biceps brachii(long head건이 bicipital groove·subacromial space 지남), Triceps brachii(long head=elbow&shoulder extension)

    어깨 움직임 통합

    • Agonist-Antagonist Co-contraction(안정성↑): squat 시 quadriceps+hamstring 동시수축(다관절근)으로 무릎안정성↑ / OKC(leg extension)는 상대적으로 안정성↓

    Foot Ligaments: 4 types(interosseous·thin dorsal·thick plantar·collateral)

    • 아치 형성: Spring lig(plantar calcaneonavicular, calcaneus→navicular, medial longitudinal arch 핵심-체중시 늘어나며 navicular 하강) → Long plantar lig(calcaneus tuberosity→2~5MT base) → Short plantar lig(plantar calcaneocuboid, long보다 심층) → 순서: plantar aponeurosis→long lig→short lig→spring lig
    • Plantar aponeurosis(=족저근막): calcaneus medial tuberosity→MT head, 근육-부위 연결하는 넓적한 건성구조

    관절과 인대

    • Subtalar+Talocrural+Distal tibiofibular joint = joint complex(복합적 움직임, subtalar 과도움직임이 talocrural로 전달→ATFL손상 가능; talocrural 단독으론 inversion/eversion 없기 때문)
    • Subtalar joint: concave talus-convex calcaneus(임상적, 실제 S자결합), hinge joint(임상표현), inversion>eversion 각도(lateral malleolus에 막힘). Composite joint(posterior=concave talus-convex calcaneus / anterior=convex talus-concave calcaneus → convex-concave rule 모두 발생, 복잡한 꼬임)
    • 인대: Interosseous talocalcaneal lig(과도한 벌어짐·외번·내번 방지), Cervical lig(과도내번 방지)
    • Subtalar axis(=oblique axis): AP축과 SI축 사이 42°, AP축과 ML축 사이 16° — 하나의 축 기준 pronation/supination 동시발생(독립불가)
    • Pronation=dorsiflexion+abduction+eversion / Supination=plantarflexion+adduction+inversion (NWB 기준)
    • WB(체중부하) 시: calcaneus 고정, talus가 움직임(반대로 보임) / NWB 시: talus 고정, calcaneus가 움직임
    • GRF가 축 lateral 이동→외번토크↑ / medial 이동→내번토크↑
    • Talocrural joint: dorsiflexion/plantarflexion, hinge joint, mortise(distal tibia+med/lat malleolus)-tenon(talus trochlea) 구조. Talus ant>post 폭차가 mortise 변동폭보다 커서 PF시 안정성↓, DF의 ROM이 더 작음
    • 외측인대: ATFL(과도 PF시 손상→talocrural instability), PTFL, CFL(과도 inversion시 손상→subtalar instability)
    • 내측인대(deltoid ligament, 더 크고 단단·회복기간 김): ATTL, PTTL, TNL, TCL(sustentaculum tali 부착)
