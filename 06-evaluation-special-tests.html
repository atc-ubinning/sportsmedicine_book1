    VI. 손상평가학 (Evaluation & Special Tests)

    1. 평가 원칙

    • 보호성근육경직 방지 위해 건측부터 검사후 환측과 비교
    • 순서: 뼈→인대→근육/건, 통증에서 먼부위→가까운부위
    • Palpation시 laxity집중, 인대는 end feel이 단단해야 정상
    • History: 3~4가지 감별진단 가능해야함(4개초과시 질문추가), yes/no질문 최소화(주관적서술유도)
    • 급성=어떻게다쳤는지 / 만성=루틴·장비·자세변화 확인

    2. HOPS / SOAP / 기타 평가체계

    > [!important] HOPS (현장초기): History → Observation → Palpation → Special test > - History: 부상의 80~90% 파악가능, primary complaint·injury area·MOI·과거력 > - Observation: 자세·부상부위변화, 건측비교필수 > - Palpation: bumps·dents·crepitus(골절징후)·malalignment·조직밀도·dermatome > - Stress(Special) test: goniometry·MMT·관절안정성/가동성·신경학적검사

    체계 용도 구성
    SOAP 병원·AT·물리치료 Subjective / Objective / Assessment / Plan
    DOTS 신체검사(근위→원위 순) Deformity / Open wounds / Tenderness / Swelling
    OPQRST 통증 Onset / Provocation·Palliation / Quality / Region·Radiation / Severity / Time
    DCAP-BTLS 외상평가 Deformities / Contusions / Abrasions / Punctures / Burns / Tenderness / Lacerations / Swelling

    3. Primary Survey (생명위협 판단)

    > [!danger] 순서: 신경계 → 호흡계(최우선) → 순환계

    계통 평가
    신경계 AVPU: Alert / Verbal반응 / Painful반응 / Unresponsive
    호흡계 시각(가슴움직임)/청각(숨소리)/촉각(날숨). 기도확보(경추손상의심시 장비제거말고 처치), jaw thrust method
    순환계 요골·경동맥, 청색증, 내외출혈여부

    > [!warning] Shock > 부적절순환, 교감신경활성화(빠른맥박·차가운피부·출혈·갈증·땀), 처치=supine+다리거상+체온유지(척추손상의심시 이동금지)

    4. ROM 평가

    종류 설명
    AROM(능동) 근력·신경지배·통증회피·운동조절 모두반영, 먼저측정
    PROM(수동) 검사자·중력, 일반적으로 AROM보다범위큼 → AROM이 PROM만큼 안나오면 근육문제의심
    AAROM 보조능동
    RROM 저항, 근력검사
    • PROM 제한요인: 관절낭뻣뻣함, 인대유착, 근경련, 근건/근막뻣뻣함, 통증, 관절삼출, 골성차단(정상 or 병리)
    • End feel: normal(ligament·capsule·bony 등) vs pathological(cartilage tear·swelling·pain·spasm·bony piece)
    • 근육손상=PROM·AROM 모두 통증가능(사용시통증) / 인대손상=늘어날때만 통증
    • Goniometer: motion angle(개인자세기준) vs ROM(중립기준), pivot=회전축, fixed arm=근위기준축, moving arm=원위움직임부

    5. 근력 평가

    • MMT: 0~5등급(3등급=중력버팀), Break test 여러각도 시행
    • MMT원칙: 관찰(부드러움·근육윤곽·수축·보상작용) → 적절자세 → 근육군고립및안정화(원위부저항,근위부고정) → 지속적이고점진적힘(작용선방향) → 반드시건측비교
    • 대근육: 1RM측정

    6. Special Tests (부위별)

    🦶 Foot & Ankle

    Test 대상 방법 요지
    Ottawa ankle rules 골절 med/lat malleolus·navicular·5th MT base 촉진+5보행가능여부
    Anterior drawer test ATFL 중립위, 거골 전방견인
    Talar tilt(inversion) CFL
    Talar tilt(eversion) Deltoid
    Kleiger's test Deltoid or 골간막 중립+외회전=deltoid, 완전DF+외회전=high ankle
    Thompson's test Achilles prone, 비복근수동압박, PF안나오면 파열의심

    🦵 Knee

    Test 방법/대상
    Ottawa knee rules fibula head·patella·90°굴곡·4보행·55세이상 중 하나라도 해당시 골절의심
    Valgus stress test MCL(0°=deep MCL·ACL·PCL / 30°=superficial MCL)
    Varus stress test LCL(0°=LCL·ACL·PCL / 30°=LCL만)
    Lachman test 20°굴곡, tibia·femur잡고 전후, ACL
    Anterior/Posterior drawer test 45°or90°굴곡, 경골전후방, ACL/PCL
    McMurray's test tibia중립/외회전/내회전에서 valgus·varus, popping/locking→meniscus(내회전=외측구조·외회전=내측구조)
    Thessaly test 한발서기5~20°굴곡+몸통회전, meniscus
    Ober's test 측와위 고관절신전+외전후 낙하, ITB tightness(수평유지시 양성), TFL긴장시 다리전방이동

    🦴 Hip

    Test 대상
    Thomas test iliopsoas·rectus femoris 단축
    Ely's test rectus femoris단축(prone, 무릎90°굴곡시 tenting)
    Hip scour test 골두 회전
    SI-joint compression/distraction test SI joint

    💪 Shoulder

    Test 대상/요지
    AC compression / traction·sulcus / tap test AC joint 손상 / laxity / clavicle fracture
    Anterior Apprehension / Relocation(Jobe) / Anterior Release 전방불안정성(90°외전+외회전)
    Neer's / Hawkins-Kennedy / Empty can 충돌증후군·극상근(3개조합시 RC병변 정확도≈99%)
    Drop Arm RC병변(속도조절불가)
    Compression-Rotation(Crank) labrum손상

    💪 Elbow

    chair sign(UCL·회전불안정) / valgus·varus stress test(MCL·LCL, 완전신전에선평가X-olecranon fossa locking) / lateral epicondylalgia검사(Mill's·Cozen's) / Hook test·Luddington's test(biceps rupture)

    ✋ Wrist/Hand

    Phalen's test(carpal tunnel), TFCC press test, scaphoid compression test, grip strength test(골절)

    🦴 Lumbar/Thoracic

    Adam's forward bend(scoliosis) / SLR(disc herniation) / tension sign(디스크성신경압박) / Milgram test(nerve root impingement) / Quadrant test(신경vs facet문제) / single leg stance test(spondylolisthesis)
