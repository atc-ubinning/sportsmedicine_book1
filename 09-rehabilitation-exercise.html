    IX. 재활운동학 (Rehabilitation & Therapeutic Exercise)

    1. 재활 프로그램의 단계 (치유3단계 기반, 통합)

    Phase 정의 목표 다음단계 진행기준
    🛡️ I. Protective/보호기 손상·수술직후, 염증에의한 제한 재손상방지, 적절보행교육, 근력손실최소화, 체력유지 고정제거, 통증·부종·경련 충분히↓
    🔧 II. Repair·Restorative/회복기 활발한치료적운동(ROM포함)시작 점진적체중부하, ROM/근력/근지구력/고유수용감각회복, 재손상보호(테이핑) 거의완전ROM, 건측근력60%
    📈 III. Maturation/성숙기 조직치유+전신재컨디셔닝 ROM·유연성·고유수용감각·근력·파워·지구력 최적화, 종목특이훈련 건측근력70~80%, 민첩성초기훈련 올바른자세
    ✅ IV. Maintenance/유지기 복귀이후 유지 —
    ❗ 중요 — 재활 7대원칙
    손상악화방지 · 시기적절성 · 환자순응도 · 개별화 · 체계적순서(과학적근거) · 적절한강도 · 전인적환자관리
    약어 의미
    ATC IS IT Avoid aggravation(과도진도지양) / Timing(안아픈데부터빨리) / Compliance(흥미유지) / Individualization / Specific sequencing(치유단계순서) / Intensity(안아픈선강도↑) / Total patient(전인적)
    3P positive · planned · properly progressive
    4I identify · isolate · intensity · integrate

    검사·평가·목표설정: 부상순간~복귀준비까지 지속. 회복단계파악이 핵심지표. 측정가능한목표(4단계순차, NRS 등 주관지표), 재평가로 지속검토. 방해요인=비현실적목표, 과보수/과공격계획, 잘못된치료법, 비순응

    2. ROM·유연성

    개념 설명
    유연성 연부조직 탄성+신장성(주로근육길이, 수동움직임제한요소)
    ROM 관절가동각도(구조+주변조직복합결과)
    • ROM감소원인: 관절낭뻣뻣함, 인대유착, 근경련, 근건/근막뻣뻣함, 통증, 관절삼출, 골성차단
    💡 팁 — 시간경과시 부상위험↓하나 가소성도↓ → 적절시기재활필요(늦으면유착)
    • PROM/AROM/AAROM/RROM (VI장 참조) — 주의: 염증·ROM통증시, 골다공증·골성강직, 연부조직손상직후, 혈우병·혈종부위 시행주의
    • Elasticity vs Plasticity: elasticity(원래길이복원) / plasticity(모양·크기변화허용) — parallel increase(섬유단면적↑, 근력↑) vs series increase(섬유길이↑, ROM↑)

    3. 근력강화 원칙

    ❗ 중요 — SAID Principle
    특정자극에 특정방식대응 → 종목·선수특이적운동. 역학적특이적응(하중·동작), 신경근특이적응(수축·운동속도), 대사특이적응(반복수·세트수·속도·휴식)
    • 훈련4대원칙: 과부하, 변형(주차별계획변화), 개별화, 적응
    • 설계요소: 운동선택(보조·고립 vs 멀티조인트), 장비, 빈도, 순서, 휴식·저항·부하

    🏗️ 부상재활 4단계(근력관점)

    Phase 특징 목표 진행기준
    1 조직복구시작, 염증·통증존재 조직보호, 제한ROM회복, 근억제방지 건측ROM75%+, 통증최소
    2 사용범위증가, 염증감소 지속보호+기능회복 거의완전ROM, 건측근력60%
    3 정상관절운동, 근성능향상 근지구력·근력·심혈관지구력, 신경근조절회복 건측근력70~80%
    4 완전기능복귀준비 종목특화훈련, 재부상방지 —
    📝 참고 — 주기화
    선형(지구력→근력→파워순차) vs 비선형(여러요소동시발전 — 재활은비선형이더적합, 재활선수도가능범위내 팀훈련통합권장)

    🏋️ 저항운동 4종류(운동참여수준)

    종류 설명
    Passive 근력개선無, ROM·고유수용감각·순환↑
    AA(보조) 근력유지+고유수용감각
    Active 중력저항, ROM·근력·지구력
    Resistive 근력향상최적. manual(검사자수기,PNF,초중기다관절) · mechanical(기구,단관절) · functional(스쿼트·푸쉬업,다관절CKC)
    • Immobilization tissue: 위축→세포크기↓→요구없음→수축없음(악순환) — 계속부하로 근비대 필요(SAID)

    4. 감각운동시스템·고유수용감각·신경근조절

    용어 설명
    Proprioception(고유수용감각) 근육·힘줄·인대·관절·근막 구심정보로 위치·움직임·힘 인지
    Kinesthesia(운동감각) 관절움직임·가속도인지
    JPS(관절위치감각) 정적 감각

    감각운동시스템: 기능적관절안정성 유지관여(감각+운동요소+중앙통합), 항상성유지능력

    📡 구심성정보 3출처

    # 출처 설명
    1 전정시스템 정적(이석기관2)+동적(반고리관3)균형
    2 시각시스템 느리나안정적, 해석오류가능(환경움직임=자기움직임오인) → 빠른위치변화활동은 시각의존↓·전정체성감각의존↑훈련
    3 체성감각시스템(가장광범위) 비특이수용기(통증·온도) / 피부수용기(Merkel·Meissner·Ruffini·Pacinian) / 고유수용감각수용기(관절기계수용기[변형↑=발화↑]: Ruffini·Pacinian·Golgi organ·자유신경종말 / 근-건수용기: GTO[수축→이완=자가억제]·근방추[신장→수축=상호억제] / 근막기계수용기)
    • 경로: 말초→구심경로→척수(반사, 단일시냅스=초고속[근방추→수축] vs 다중시냅스=느림[GTO→이완])→뇌간(1차처리, 시각·전정·체성통합)→대뇌피질(의식적조절, 연습으로자동화)→피질하핵·소뇌도관여
    ❗ 중요 — 인대의 두속성
    Mechanical + Sensory property (인대→γ시스템→근방추→α운동뉴런→근수축) → 기계적결함회복되어도 감각적결함남으면 불안정지속
    ⚠️ 주의 — 고유수용감각손실 원인
    나이·피로·고정·손상·수술·관절염 → JPS·운동감각↓, 반응지연, 신경근조절패턴변화 → 재손상위험↑

    신경근조절(정의): 구심입력에대한 적절원심반응

    • 재활원리: 말초구심수용기재활(feedforward예측+feedback즉각수정) / 근육경직도재활(GTO둔감화, 근방추활성화)

    🔀 두 활성화전략

    전략 특징
    반사적(feedback) 척수반사회로
    차별적/예비(feedforward) 상위중추, 느리나정확, 의식→무의식전환
    • Feedforward(과거경험기반, 사전준비) vs Feedback(반사경로, 느린움직임·자세조절적합) — 통합시 동적안정성↑
    • 훈련목표: 근육단위자극빈도↑, 운동단위발화동시성↑, 감각정보유용성↑, 운동감각인식↑
    • 진행순서: 정적평가·운동감각훈련→동적안정화→반응적신경근조절→기능적활동
    ❗ 중요 — 4대축: 균형 · 협응 · 플라이오메트릭 · 민첩성
    공통원칙: 단순→복합, 통제→반응, 정적→동적

    5. 균형과 협응

    ⚖️ 균형(Balance)

    무게중심을 지지면위에서 통제하는능력.

    ⚠️ 주의 — 균형부족 = 부상·재부상위험↑ (노인낙상 동일기전)
    • Sensory+motor 통합, 지속적조절필요
    • 평가: COP오차↓=균형↑(장비: 지면반력기·IMU / 무장비: SEBT·Y-balance)
    • Progression: 정적→동적→반응적

    🤸 협응(Coordination)

    여러근육이 함께 부드러운패턴생성(자극·억제과정)

    • 구성: 활동지각→피드백(뇌간→척수하행)→반복(자동화촉진)→억제(정밀·느림·통제된활동으로만촉진, 직접훈련불가)
    • 정적→동적, 속도·힘·복잡성 점진증가, 비협응동작시즉시중단
    • 하지: CKC운동, 관절안정화, 플라이오메트릭 / 상지: 정적안정구조물(인대·관절낭·관절순)고려, 관절정합성, 근강성강화

    6. 플라이오메트릭

    역할: 근력↔경기력 연결다리, 근육이최대한빨리최대강도출력하도록촉진

    ℹ️ 정보 — SSC(신장-단축주기)
    편심성수축→구심성수축 빠른전환
    - 기계적기전(SEC/PEC/CC): CC(수축요소,능동힘) / PEC(병렬탄성,근막,신경자극없이작동) / SEC(직렬탄성,건+교차결합, CC힘생성시 먼저늘어나탄성에너지저장·방출=SSC기계적기반)
    - 신경학적기전: 근방추신장반사(급격신장→수축촉진) / GTO억제(근방추보다약간느림)

    7. 속도와 민첩성

    개념 설명
    Speed 높은이동속도달성기술
    COD(방향전환) 폭발적변경
    Agility(민첩성) 자극반응 방향전환=인지능력+신체능력 — ①지각·의사결정(시각탐색·상황지식·패턴인식·예측) ②방향전환속도(직선스프린트·신체계측)

    움직임제어3단계: 근육(반사)→뇌간(자세·평형·자동화)→CNS(의도적계획·전략) — 시각·전정·기계수용기정보가CNS통합

    ❗ 중요 — 3단계재활모델
    ① 고유수용감각+정적안정성 ② 동적안정성 ③ 반응성신경근제어
    - 진행기준: 목표달성, 자동화(집중력덜필요), 환자체감난이도, 기술완벽수행
    기술 특징
    폐쇄기술 환경변화없음, 사전계획
    개방기술 변화환경·예측불가, 지각의사결정필수
    • 민첩성분류: 단순→시간적→공간적→보편적(시공간불확실성). 개발원칙: 단순→복합, 계획→반응, 저속→고속, 단거리→장거리
    • 신체제어·속도·정밀성·효율성개발→집중력↑→자동화(운동학습최종단계)
    • 테스트: 505 agility test, T-test / 모니터링: 방향전환질, 지면접촉시간, 탈출·진입속도, 의사결정시간
